# Kienora Excel AI V1

## Chức năng
- Mở `.xlsx/.xls/.csv` ngay trên trình duyệt.
- Chỉnh sửa trực tiếp kiểu bảng Excel.
- Tải file Excel sau khi sửa.
- Nhập lệnh tiếng Việt cho AI.
- AI chỉ tạo **danh sách thay đổi đề xuất**.
- Có bước **Xem trước → Áp dụng**.
- Có **Hoàn tác / Làm lại**.

## Cài đặt
1. Cài Node.js 20+.
2. Mở terminal trong thư mục dự án.
3. Chạy `npm install`.
4. Sao chép `.env.example` thành `.env`.
5. Điền `OPENAI_API_KEY`.
6. Chạy `npm start`.
7. Mở `http://localhost:3000`.

API key chỉ nằm ở backend, không đặt trong HTML/JavaScript trình duyệt.
